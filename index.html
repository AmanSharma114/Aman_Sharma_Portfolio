TCS internal / regulated data

Pharma Data Ingestion & Versioning Platform

Reusable Glue framework with full historical audit trails

Problem: Onboarding third-party lab data at 100K+ records scale required schema validation, deduplication, and a reliable audit trail—without duplicating data on reprocessing.

Third-Party Lab Data → S3 → AWS Glue (PySpark) [schema validation | dedup | 4 config-driven document types] → PL/pgSQL SCD Type 2 → Aurora PostgreSQL → Airflow-orchestrated, idempotent workflow → Athena
AirflowAWS GluePySparkPL/pgSQLAurora PostgreSQLSCD Type 2
Read full case study + production incident

Key decisions

Built config-driven ingestion rather than per-document-type pipelines: a new regulated document is a configuration change. Business-key hashing plus PL/pgSQL SCD Type 2 preserves history. Disposable staging tables make Airflow re-runs safe.

Production incident

A dp_stab pipeline produced duplicate batch records due to an unscoped JOIN on TEST_ARTICLE. I traced the multiplication, scoped the JOIN, added a LIMIT 1 subquery to guarantee one match per batch, and validated expected record counts against historical runs.

Validation

Confirmed historical versions remained intact across reprocessing, then re-ran pipelines to verify record counts stayed constant rather than growing.

Learning

Duplicate JOIN defects seldom throw errors—they quietly corrupt downstream numbers. Explicit quality layers and count checks are as important as code inspection.

Enterprise AI / multi-agent

Enterprise AI Support Copilot

Classifies incidents, retrieves context, returns a cited root cause

Problem: Support engineers lose hours cross-referencing SOPs, Confluence, docs, and historical incidents to determine a root cause.

Incoming incident → LangGraph classifier → Hybrid retrieval [BM25 + dense vectors] → Cross-encoder reranker → Synthesis agent → HITL gate → cited recommendation → MCP diagnostics
LangGraphRAGMCPFastAPIHITL
Read architecture and evaluation

Decision

Hybrid retrieval with cross-encoder reranking surfaces the right documentation and past incidents; synthesis yields one recommendation instead of raw search hits.

Evaluation

Compared with a vector-only baseline on a sample query set; hybrid retrieval produced ~35% better recall. Broader regression testing is next.

Safety

HITL gates uncertain responses; enterprise details remain generalized to respect confidentiality.

Learning

MCP closes the gap between knowledge retrieval and action execution; an intent-classification node improves tool routing consistency.

Personal project / AI & LLM

LegalMind — Indian Legal AI Agent

Source-grounded answers, not plausible legal guesses

Problem: General LLMs hallucinate citations and misread jurisdiction-specific law. Legal professionals cannot trust uncited answers.

User query → Legal-BERT embeddings → Pinecone top-k → Context + citation tracking → LangGraph ReAct [search | summarise | clause extract | HITL] → FastAPI streaming → Streamlit
Legal-BERTPineconeLangGraphFastAPIStreamlit
Read full system rationale

Decision

Legal-BERT was selected over general embeddings for legal semantic understanding; LangGraph gives explicit, stateful conditional reasoning.

Safety

Citation-enforced responses: uncertain answers escalate instead of guessing. HITL is an architectural requirement, not a fallback.

Evaluation

Manual QA covered representative queries, missing context, ambiguous jurisdiction, and adversarial phrasing. DeepEval regression checks are the next planned step.

Personal project / AWS data

YouTube Trending Data Pipeline

Serverless Bronze–Silver–Gold on AWS

Problem: Track trending-video signals across regions on a schedule without maintaining servers or a permanent orchestration cluster.

EventBridge / 6hr → Step Functions → YouTube Data API v3 / 10 regions → Bronze S3 → Glue reconciliation → Lambda quality checks → Silver → 3 partitioned Gold Parquet/Snappy datasets → Athena + SNS
GlueStep FunctionsEventBridgeLambdaAthena
Read design and validation

Decision

Fully serverless design eliminates idle cost and cluster operations. Dedicated reconciliation handles response-shape drift between regions.

Quality

Lambda checks data before promotion, so bad responses do not silently contaminate curated datasets.

Impact

10 regions every six hours; three analytics-ready datasets; zero servers to manage.

Validation

Failures surface through SNS. Gold outputs were spot-checked in Athena for partitioning and record counts.
