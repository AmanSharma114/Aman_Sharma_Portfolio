# Aman Sharma | Data Engineering Portfolio

I build and maintain AWS Glue pipelines that process 5–10 GB of pharmaceutical data daily. My portfolio covers that production work and personal projects in data engineering and retrieval-augmented generation.

## Selected projects

- **Pharma data ingestion and versioning** — A production case study on validating incoming records, preserving history in Aurora PostgreSQL, and tracing duplicate records to a join. [Read the case study](https://amansharmamudgal.netlify.app/#systems)
- **PipelineOps Copilot** — A public support desk that retrieves recovery steps from synthetic runbooks and links to the source passages. The repository includes retrieval evaluations and a local RAG example. [Try the demo](https://pipelineops-freight-copilot.aamansharmamu114.chatgpt.site/) · [View source](https://github.com/AmanSharma114/Pipelineops-copilot)
- **YouTube Trending Data Pipeline** — An AWS pipeline that collects trending videos across ten regions every six hours and publishes partitioned Parquet datasets for queries in Athena. [View source](https://github.com/AmanSharma114/Yotube_Data_Pipeline_DE_Project)

## Run the portfolio locally

The site uses HTML, CSS, and JavaScript. Open `index.html` in a browser, or serve the repository with Python 3.

```bash
git clone https://github.com/AmanSharma114/Aman_Sharma_Portfolio.git
cd Aman_Sharma_Portfolio
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). To deploy on Netlify, publish the repository root and leave the build command empty.
